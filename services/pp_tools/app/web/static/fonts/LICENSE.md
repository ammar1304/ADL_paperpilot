# Fonts

Newsreader (Production Type), Schibsted Grotesk (Schibsted) and Caveat (Impallari Type), Latin subsets
from the @fontsource 5.3.0 packages. All three are licensed under the SIL Open Font License 1.1
(https://openfontlicense.org), which allows bundling them with software. They are served by
pp-tools so the web app works without internet access.
